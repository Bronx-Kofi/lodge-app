## 1. Homepage Content

### What You Can Edit:
- Hero section (image, headline, tagline)
- Features/Value propositions
- Featured rooms selection
- WhatsApp button settings

### How to Update:

#### Step 1: Open Homepage in Studio
1. Go to: http://localhost:3333
2. Click: **"Homepage"** in left sidebar

#### Step 2: Edit Hero Section
**Hero Headline** (Tab: Hero Section):
- Current: "Welcome to the Hillside"
- Example: "Welcome to Miky Hillside Lodge"
- Keep it short: 5-8 words

**Hero Subtitle** (Tab: Hero Section):
- Current: "Off-grid luxury meets authentic Ghanaian hospitality"
- Example: "Experience luxury in Ghana's beautiful Bono Region"
- Keep it: 10-15 words

**Hero Image** (Tab: Hero Section):
1. Click: "Select" button
2. Choose: Upload new image OR select from media library
3. **Recommended size**: 1920x1080 pixels (landscape)
4. **File size**: Under 200KB (compress first at Squoosh.app)
5. **Format**: JPG or WebP

**Hero Video** (Tab: Hero Section) - Optional:
1. Click: "Upload"
2. **Format**: MP4
3. **Max size**: 20MB
4. **Recommended**: 10-15 seconds, 1920x1080
5. Video plays instead of image on desktop

#### Step 3: Edit Features Section
**Features Section Title** (Tab: Features):
- Example: "Why Choose Hillside"
- Example: "The Hillside Promise"
- Example: "What Makes Us Special"

**Add Features** (Tab: Features):
1. Click: **"+ Add item"** button
2. Fill in:
   - **Title**: Short (3-5 words). Example: "Off-Grid Luxury"
   - **Description**: 1-2 sentences. Example: "Experience modern comfort powered by sustainable solar energy and starlink connectivity"
3. Add 3-4 features total (recommended)
4. Drag to reorder

**Example Features**:
```
1. Title: "Off-Grid Luxury"
   Description: "Modern comfort powered by sustainable solar energy and Starlink connectivity"

2. Title: "Authentic Hospitality"
   Description: "Experience genuine Ghanaian warmth and traditional akwaaba welcome"

3. Title: "Breathtaking Views"
   Description: "Wake up to stunning hillside vistas across the Bono Region landscape"

4. Title: "Local Heritage"
   Description: "Explore nearby cultural sites and immerse yourself in rich local traditions"
```

#### Step 4: Select Featured Rooms
**Featured Rooms Title** (Tab: Featured Rooms):
- Example: "Our Rooms"
- Example: "Choose Your Sanctuary"

**Select Rooms to Feature** (Tab: Featured Rooms):
1. Click: **"+ Add item"**
2. Click: **"Select"** button
3. Choose: A room from your list
4. Add 3-6 rooms (recommended)
5. These show on homepage

#### Step 5: WhatsApp Settings
**Show WhatsApp Button?** (Tab: WhatsApp Button):
- Toggle: ON to show floating WhatsApp button
- Toggle: OFF to hide

**Pre-filled Message** (Tab: WhatsApp Button):
- Example: "Hi! I'm interested in booking a room at Miky Hillside Lodge."
- This appears when guests click WhatsApp button

#### Step 6: Publish
1. Click: **"Publish"** button (green, bottom of page)
2. Wait: 10 seconds
3. Go to: http://localhost:3002
4. Press: **Ctrl + Shift + R** (hard refresh)
5. Your changes appear!

## 2. Site Settings (Header & Footer)

### What You Can Edit:
- Site name (appears in header and footer)
- Tagline
- Logo
- Contact information
- Social media links
- Check-in/check-out times

### How to Update:

#### Step 1: Open Site Settings
1. Go to: http://localhost:3333
2. Click: **"Site Settings"** in sidebar

#### Step 2: Edit Name & Logo (Tab: Name & Logo)

**Lodge Name**:
- Current: "Miky Hillside Lodge"
- This appears:
  - Top-left header
  - Footer heading
  - Browser tab title
  - Copyright text

**Tagline**:
- Example: "Luxury in the Heart of Bono Region"
- Appears in:
  - Footer subtitle
  - Page meta descriptions (SEO)

**Logo**:
1. Click: "Upload"
2. **Recommended**: PNG with transparent background
3. **Size**: 200x50 pixels (approximate)
4. **Max file size**: 100KB

#### Step 3: Edit Contact Info (Tab: Contact Info)

**Phone Number**:
- Format: Any format works
- Example: 0256945566
- Appears in footer

**WhatsApp Number**:
- Format: **233240000000** (no + or spaces)
- Start with country code (233 for Ghana)
- Used for floating WhatsApp button

**Email Address**:
- Example: info@mikyhillside.com
- Appears in footer

**Physical Address**:
- Example:
  ```
  Sunyani-Dumasua Road
  Bono Region, Ghana
  ```
- Use line breaks for formatting
- Appears in footer

#### Step 4: Edit Social Media (Tab: Social Media)

**Important**: Use **full URLs** including https://

**Facebook Page URL**:
- Example: https://facebook.com/mikyhillside
- Icon appears in footer when filled

**Instagram Profile URL**:
- Example: https://instagram.com/mikyhillside
- Icon appears in footer when filled

**Twitter/X Profile URL**:
- Example: https://twitter.com/mikyhillside
- Icon appears in footer when filled

#### Step 5: Edit Operations (Tab: Operations)

**Check-in Time**:
- Example: "2:00 PM"
- Example: "14:00"

**Check-out Time**:
- Example: "11:00 AM"
- Example: "11:00"

**Currency Code**:
- Default: "GHS" (Ghana Cedis)
- Or: "USD", "EUR", etc.

#### Step 6: Publish
1. Click: **"Publish"**
2. Wait: 10 seconds
3. Refresh: http://localhost:3002 (Ctrl+Shift+R)
4. Changes appear in header and footer!

## 3. Rooms & Accommodations

### What You Can Edit:
- Room title, tagline, description
- Price and capacity
- Images (main photo + gallery)
- Amenities

### How to Update Existing Room:

#### Step 1: Open Rooms
1. Go to: http://localhost:3333
2. Click: **"Room"** in sidebar
3. Click: Your room (e.g., "Garden View Room")

#### Step 2: Edit Basic Info (Tab: 1. Basic Info)

**Room Name**:
- Example: "Garden View Suite"
- Keep it short and descriptive

**Tagline**:
- Example: "Peaceful retreat with stunning garden views"
- 8-12 words recommended

**Full Description**:
1. Click: **"+ Add item"** button (important!)
2. Type: First paragraph
3. Click: **"+ Add item"** again for next paragraph
4. Add 2-3 paragraphs
5. Each paragraph is a separate block

**Example Description**:
```
Paragraph 1:
Perched on the highest point of the property, The Hillside Suite offers 
unmatched privacy and breathtaking vistas across the Bono Region.

Paragraph 2:
This spacious open-plan room features a king-sized bed, sustainable local 
teak furniture, and large windows that flood the space with natural light.

Paragraph 3:
The private terrace is the perfect spot for morning coffee or star-gazing 
at night. Includes a modern en-suite bathroom with solar-heated rainfall shower.
```

**Price per Night**:
- Enter: Number only (e.g., 350)
- Currency is set in Site Settings (default: GHS)

**Maximum Guests**:
- Enter: Number (e.g., 2)
- Indicates capacity

#### Step 3: Edit Photos (Tab: 2. Photos)

**Main Room Photo**:
1. Click: "Select" or current image
2. Upload: Your best room photo
3. **Recommended size**: 1200x800 pixels
4. **Max file size**: 150KB (compress first)
5. This shows on room cards

**More Photos (Gallery)**:
1. Click: **"+ Add item"**
2. Upload: Image
3. Fill in:
   - **Alternative Text**: Describe image (for accessibility)
   - **Caption**: Optional description
4. Add 5-10 images showing:
   - Different room angles
   - Bed close-up
   - Bathroom
   - View from window
   - Terrace/balcony
   - Unique features

#### Step 4: Edit Pricing (Tab: 3. Pricing & Capacity)

**Base Price**:
- Already set in Basic Info
- Can adjust here too

**Maximum Occupancy**:
- Already set in Basic Info

#### Step 5: Select Amenities (Tab: 4. Features & Amenities)

Check all that apply:
- ☑ WiFi / Starlink Internet
- ☑ Air Conditioning / Fan
- ☑ Private Bathroom
- ☑ Hot Water
- ☑ Balcony / Terrace
- ☑ Garden View
- ☑ King Bed / Queen Bed / Twin Beds
- ☑ Workspace / Desk
- ☑ Towels & Linens
- ☑ Toiletries
- ☑ Coffee/Tea Maker
- ☑ Mini Fridge
- ☑ Safe
- ☑ Wardrobe / Closet

#### Step 6: Publish
1. Click: **"Publish"**
2. Wait: 30 seconds
3. Visit: http://localhost:3002/rooms
4. Click: Your room
5. All changes appear!

### How to Add New Room:

#### Step 1: Create Room
1. Go to: http://localhost:3333
2. Click: **"Room"** in sidebar
3. Click: **"+ Create"** button (top right)
4. Choose: **"Room"**

#### Step 2: Fill in All Tabs
Follow steps 2-5 above (same as updating existing room)

#### Step 3: Create URL Slug
**Slug (URL)** (in Basic Info):
- Example: "deluxe-suite"
- Example: "garden-view-room"
- Use lowercase, hyphens (no spaces)
- This becomes the URL: `/rooms/deluxe-suite`

#### Step 4: Publish
1. Click: **"Publish"**
2. Room appears on: http://localhost:3002/rooms
3. Detail page: http://localhost:3002/rooms/YOUR-SLUG

## 🚨 Troubleshooting

### "Changes Don't Appear"
1. Did you click "Publish"? (not just save)
2. Wait 10-30 seconds
3. Hard refresh: Ctrl + Shift + R
4. Clear browser cache
5. Try incognito mode

### "Images Look Blurry"
1. Check original image quality
2. Upload higher resolution
3. Images are auto-optimized to 80% quality (good for web)
4. If needed, contact for quality adjustment

### "Room Description Doesn't Show"
1. Make sure you clicked "+ Add item"
2. Description must be in block format (not plain text)
3. Each paragraph is separate block
4. Click "Publish" after adding

### "WhatsApp Button Not Working"
1. Check number format: 233240000000 (no + or spaces)
2. Start with country code (233 for Ghana)
3. Verify WhatsApp is enabled in Homepage settings
4. Number is set in Site Settings, not Homepage
