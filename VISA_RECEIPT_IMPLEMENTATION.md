## 🆘 Troubleshooting

### Issue: Button doesn't appear
**Fix:** Make sure you're viewing the standard receipt page first

**Fix:** Use browser's print dialog → "Save as PDF"

### Issue: Missing guest information
**Fix:** Ensure booking has all required fields (nationality, passport)

### Issue: Lodge details incorrect
**Fix:** Update in Sanity Studio → Site Settings
