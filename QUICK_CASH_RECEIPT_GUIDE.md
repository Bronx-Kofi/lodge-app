# Quick Guide: Cash Payment Receipts

## 🎯 For Walk-In Guests Who Pay Cash

### 3-Minute Process

---

## Step 1: Create Booking (2 minutes)

Go to: **your-domain.com/studio** → **Bookings** → **+ Create**

### Fill These Tabs:

**Tab 1 - Guest Info:**
- Name, Email, Phone ✓

**Tab 2 - Dates & Room:**
- Select Room ✓
- Check-in/Check-out dates ✓

**Tab 3 - Pricing:**
- Total Price ✓
- Status: **Confirmed** ✓

**Tab 4 - Payment:** ⭐ **IMPORTANT!**
- Status: **Paid in Full** ✓
- Amount Paid: [full amount] ✓
- Method: **Cash** ✓
- Reference: Cash-[today's date] ✓

**Click Publish!**

---

## Step 2: Give Guest Receipt (30 seconds)

### Receipt URL Format:
```
your-domain.com/receipt/visa?ref=BOOKING_REF&email=GUEST_EMAIL
```

### Example:
```
your-domain.com/receipt/visa?ref=MHL-12345678&email=john@email.com
```

### How to Share:
- 📱 SMS the link
- 📧 Email the link
- 💬 WhatsApp the link
- 🖨️ Print it (Ctrl+P on the receipt page)

---

## 🆘 Quick Help

**Booking Reference Auto-fills:** MHL-12345678 (you can change it)

**Guest has no email?** Use: `walkin-[date]@mikyhillside.com`

**Made a mistake?** Edit the booking and Publish again

**Print receipt?** Open receipt URL and press Ctrl+P
