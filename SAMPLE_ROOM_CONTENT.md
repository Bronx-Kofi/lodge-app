## 🎯 How to Add These Rooms

### Step 1: Go to Sanity Studio
**http://localhost:3002/studio**

### Step 2: Create New Room
1. Click "**Room**" in left sidebar
2. Click "**+ Create**" or "+ New Document"
3. Select "Room" type

### Step 3: Fill in Each Tab
Use the content above for each of the 6 tabs:
1. ✅ **Basic Info** - Name, description, slug
2. ✅ **Photos** - Upload images
3. ✅ **Price** - Set pricing
4. ✅ **Who Can Stay** - Max guests, bedding
5. ✅ **What's Included** - Select amenities
6. ✅ **Additional Details** - Cancellation policy

### Step 4: Publish
Click "**Publish**" button at bottom-right

### Step 5: Repeat
Create all 3 rooms using the content above

## 💡 Tips for Adding Rooms

### Photos:
- **Don't have real photos?** Use placeholder images for now
- **Where to get stock photos:**
  - Unsplash.com (free)
  - Pexels.com (free)
  - Search: "hotel room", "bungalow", "suite interior"

### Pricing Strategy:
- **All rooms** - Fixed rate: GHS 367/night
- Consistent pricing simplifies booking
- Value varies by room size, amenities, and capacity

### Amenities:
- More amenities = Higher price justified
- Standard rooms: Basic amenities
- Deluxe/Suites: Premium amenities
- Bungalows: Maximum amenities + privacy

### Descriptions:
- Keep it descriptive but concise
- Highlight unique features
- Mention what makes each room special
- Be honest about what's included
